# Context Discipline

Keep active context proportional to the current decision and proof obligation.

Load only:

- current outcome;
- current slice;
- relevant guardrails and resolved decisions;
- target implementation/contracts;
- target tests/evidence.

Prefer symbols, focused ranges, diffs, compact state, and distilled results over whole repositories, raw logs, or historical narrative.

Treat context pressure as observable when there is repeated rediscovery, contradictory summaries, buried outcome/guardrails, tool-output crowding, wrong-worktree uncertainty, or inability to state the next proof obligation.

When pressure appears:

1. checkpoint only authoritative position/state that must survive;
2. reconcile repository and worktree identity;
3. discard irrelevant narrative;
4. reload from real artifacts and Git;
5. continue the first unproven necessary slice.

Delegate a bounded read-heavy problem only when isolation reduces net context or improves genuine independence.

A compact handoff points to authoritative artifacts and hashes; it does not duplicate them.
