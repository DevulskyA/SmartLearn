# Security Router

Classify relevant work as product security, harness security, or both. A green scanner in one category does not prove the other.

- Read [product-security.md](product-security.md) when implemented behavior crosses identity, authorization, tenants, secrets, external input, data access, uploads, URLs, commands, templates, deserialization, webhooks, or sensitive state.
- Read [harness-security.md](harness-security.md) when tools, hooks, MCP, agent configuration, repository instructions, credentials, package execution, or external actions are involved.

For each material threat, identify the protected asset, actor capability, trust boundary, attack path, expected control, negative criterion/test, detection signal, and residual risk. Security work closes only when the control is exercised, not merely named.
